Agent Gauge

A small, free Mac app that shows how much of your Claude Code and Codex limits is left, and when they reset. It lives in the menu bar and doesn’t need an account.

Download 0.1.3 Zip, 0.9 MB · macOS 14 or later · Apple silicon and Intel · Signed and notarized · MIT license

Reading the icon

Two rings
The outer ring is the weekly limit, the inner ring the 5-hour window. Each one shows what’s left, not what’s used.
Color
A ring keeps its agent’s color until less than 25% is left. Then it turns orange, and red under 10%.
Age of the reading
Claude Code only reports usage while a session is running, so the popover always says how old the numbers are. After a window resets, the old number is cleared.

Use only Claude Code, only Codex, or both. You can switch either off from the gear menu, and a hidden agent does no background work.

Where the numbers come from

Agent Gauge never asks you to sign in and never stores a token. It reads usage the way each agent already reports it on your Mac.

Claude Code

  • Claude Code passes rate-limit data to its status line. A small helper saves only the percentages and reset times to a local file.
  • No Keychain access, no tokens, no network requests.

Codex

  • Asks your installed Codex CLI for its rate limits once a minute, over a local connection.
  • Your login stays with Codex. Agent Gauge never sees a token.

Prompts, transcripts and code are never read. The source is short enough to check yourself.

Install

  1. Download the zip and unzip it.
  2. Move Agent Gauge to your Applications folder.
  3. Open it. The welcome window lets you pick your agents and connect Claude Code.

You need macOS 14 or later, and Claude Code on a Pro or Max plan, Codex on a ChatGPT plan, or both.

Build from source

Needs the Xcode command-line tools 
$ git clone https://github.com/joargp/agent-gauge.git
$ cd agent-gauge
$ ./script/install.sh

The script builds the app into ~/Applications, connects Claude Code’s status line (it leaves an existing one alone) and starts Agent Gauge. ./script/uninstall.sh removes it again.

Questions

I don’t see the icons in my menu bar.

A full menu bar, or a menu bar manager like Ice or Bartender, can hide new items. Move Agent Gauge to the visible section there.

Why is my Claude reading old?

Claude Code only reports usage while a session is open. Usage can’t grow while it’s idle, so the last reading still holds. Start a session and send a message to refresh it.

Why does my Codex 5-hour ring say “No limit on this plan”?

Some ChatGPT plans only have a weekly Codex limit. Agent Gauge shows exactly the windows Codex reports.

I already have a custom Claude status line.

Agent Gauge leaves it alone. Add one tee to your command to feed Agent Gauge too. Here’s how.

Does it work with API keys or other agents?

Not yet. It reads subscription limits for Claude Code and Codex. Each agent is a small provider in the code, so pull requests for another one are welcome.
