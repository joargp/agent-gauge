Agent Gauge: design

Every version runs the same simulated readings and moments. Use the dark bar at the top of each page to jump to a moment. Click a ring in the menu bar to open its popover.

0.3 · Current + Fable + updates

Built-in updates the Ghostty way: an update row in the popover only when there is something to show, a blue dot on the menu bar icon, and the update mode in the gear menu. Default: download quietly, install when you quit.

0.2 · Current + Fable

Current design plus a Fable row under the rings: Fable's own weekly cap, with a plain warning when it runs out before the weekly limit.

0 · Current (0.1.4)

Baseline copy of the shipping app. One menu bar icon per agent with nested rings; each opens its own popover with two large rings.
